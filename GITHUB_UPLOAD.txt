# GitHub Upload Commands

## Step 1: Initialize Git (if not already done)
git init

## Step 2: Add all code files (excluding guide files via .gitignore)
git add .

## Step 3: Commit
git commit -m "Initial commit: MedInsure blockchain health insurance platform"

## Step 4: Create GitHub repository
# Go to https://github.com/new
# Create a new repository named "medinsure" or "blockchain-health-insurance"
# Don't initialize with README (we already have one)

## Step 5: Add remote origin (replace with your GitHub username)
git remote add origin https://github.com/YOUR_USERNAME/medinsure.git

## Step 6: Push to GitHub
git branch -M main
git push -u origin main

## Alternative: If you want to push to an existing repository
git remote set-url origin https://github.com/YOUR_USERNAME/medinsure.git
git push -u origin main --force

## To check what files will be uploaded (before committing)
git status

## To see what files are ignored
git status --ignored

## To remove a file from git if accidentally added
git rm --cached filename.md
git commit -m "Remove guide file"
git push
